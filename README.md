# AuraFlow: Atmospheric Pomodoro & Soundscape Generator

AuraFlow is a polished, responsive productivity application designed to enhance deep focus and concentration. It pairs a fully customizable Pomodoro timer with a procedural ambient soundscape generator powered completely by the browser's native Web Audio API.

## Features
- **Pomodoro & Break Timers**: Seamlessly switch between Pomodoro (25m), Short Break (5m), and Long Break (15m) sessions with smooth circular SVG progress tracking.
- **Procedural Web Audio Engine**: Synthesize rich, distraction-masking ambient sounds directly in your browser—Gentle Rain, Soft Wind, Vinyl Crackle, and Ocean Waves—without external audio files.
- **Dynamic Visual Themes**: Switch between three gorgeous atmosphere themes (Midnight Nebula, Emerald Forest, Warm Amber) that transform the ambient glow and color accents.
- **Session Tracking**: Keep count of completed deep work intervals.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single local directory.
2. Open `index.html` directly in any modern web browser.
3. Note: No build tools, package managers, or server setups are required. This is a fully static client-side project.
